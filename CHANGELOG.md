# Changelog

All notable changes are listed here. Versions follow [semantic versioning](https://semver.org).

## 0.1.0 (unreleased)

First public release.

- **Vault:** end-to-end encrypted logins, cards, identities and notes; folders; generator; vault health; breach checks.
- **Teams:** organizations, groups, collections with four permission levels, invitations, policies.
- **Sign-in:** two-step login (authenticator apps, security keys, recovery codes), single sign-on (OIDC, SAML 2.0), SCIM 2.0, trusted devices.
- **Recovery:** admin-assisted account recovery, emergency access, split-key recovery kit.
- **Audit:** tamper-evident audit log, log streaming to SIEMs, compliance posture report.
- **Apps:** web vault, browser extension (Chrome, Edge, Firefox), Windows desktop app.
- **Self-hosting:** one-command installer for Linux and Windows, built-in HTTPS, backup, restore, update, offline bundle.
